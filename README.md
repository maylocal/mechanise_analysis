# mechanise_analysis

## 材料力学分析小工具

<img width="2463" height="1284" alt="图片" src="https://github.com/user-attachments/assets/cc435ecb-faa9-493b-8cfa-ad49ca259b16" />


`mechanise_analysis` 是一个面向工程技术人员和科研人员开发的轻量化材料力学分析工具，用于实现材料力学性能计算、应力应变分析、强度校核及结果可视化。

该工具以 Python 为基础，结合经典材料力学理论与工程计算方法，实现从材料参数输入、力学模型计算、结果分析到可视化展示的一体化流程。

---

# 1. 项目简介

在机械设计、航空航天、汽车制造、装备工程等领域，材料力学分析是结构设计和性能评估的重要基础。

传统材料力学分析通常依赖大型 CAE 软件（ANSYS、Abaqus、Nastran 等），但对于：

- 快速理论验证
- 教学实验
- 工程方案初步评估
- 参数敏感性分析
- AI 辅助设计数据生成

等场景，大型软件存在：

- 使用复杂
- 建模周期长
- 计算成本高
- 二次开发困难

等问题。

`mechanise_analysis` 致力于提供一个：

> 简单、开放、可扩展的材料力学计算分析工具。

---

# 2. 功能特点

## 2.1 材料参数管理

支持常见工程材料参数定义：

- 弹性模量 E
- 泊松比 ν
- 屈服强度 σy
- 抗拉强度 σb
- 密度 ρ
- 热膨胀系数 α

material = {
